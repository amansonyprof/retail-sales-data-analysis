# Retail Sales Data Analysis Project

## Objective
The objective of this project is to perform Exploratory Data Analysis (EDA) on a retail sales dataset to identify sales trends, customer behavior, and important business insights.

## Dataset
The dataset contains supermarket sales records including product categories, quantity, total sales, customer type, and payment methods.

## Files Included
- supermarket_sales.csv
- cleaned_dataset.csv
- sales_analysis.py
- requirements.txt

## Tools and Libraries Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Steps Performed
1. Data Cleaning
2. Handling Missing Values
3. Statistical Analysis
4. Data Visualization
5. Correlation Analysis

## Visualizations
- Sales Distribution
- Correlation Heatmap
- Product Category Analysis
- Payment Method Analysis

## Outcome
This project helped in understanding customer purchasing behavior and identifying important trends in retail sales data.
